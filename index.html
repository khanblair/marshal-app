How it works

Marshal is a lightweight desktop app with a background service. Each project is a Git repository with one board.

  1. One card, one task

    Describe the work on a card. Start it, and it gets an agent of its own.

  2. Its own worktree

    Each agent works in an isolated Git worktree, so many tasks run at once without breaking each other.

  3. Marshal keeps watch

    The service follows agent activity, pull requests, CI, and reviews, and moves cards as things change. You always see what needs you.

  4. Ready work gets merged

    Finished cards are merged into the branch you choose. A conflict Marshal cannot settle comes back to you.

What Marshal asks to connect, and why

You connect your own accounts, and you can disconnect at any time. Marshal runs on your computer, so these connections go from your computer to the service, not through a Marshal server.

GITHUB

Your repositories

Marshal signs in to GitHub with the Marshal Kanban GitHub App. You choose which accounts and organizations it can see, and whether that is all repositories or only some.

It is how Marshal opens pull requests, watches CI, and reads reviews.

GOOGLE CALENDAR · READ ONLY

Your calendar

Marshal reads events from the calendars you tick. It shows them next to your cards, adds today's events to your morning brief, lets a schedule start from an event, and keeps alerts quiet while you are busy.

It cannot create, change, or delete an event.

GMAIL · READ ONLY · OPTIONAL

One label

You pick a label. Marshal reads the subject, sender, and a short preview of messages carrying it, and turns each into a card once.

It cannot send, delete, label, or change any mail.

Google Calendar and Gmail each ask for their own permission, so you can use one without the other. The details, including where this data is kept, are in the privacy policy.

Privacy in short

It runs on your computer

No Marshal cloud server sits between you and GitHub, Google, or your model provider.

Keys stay in your keychain

Tokens and API keys are kept in your operating system's keychain, not in files.
