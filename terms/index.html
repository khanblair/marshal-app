Terms of service

  • Connect only accounts you are allowed to use, and follow those services' own terms.

2. What Marshal is

Marshal runs AI coding agents on Git repositories on your computer, and shows their work on a kanban board. It is in active development and is not released yet. Features can change, break, or be removed. Do not rely on Marshal for anything where a mistake would be unacceptable, unless you check the result yourself.

4. Agents act with the access you give them

An agent can read and change files, run commands, create branches, and open and merge pull requests, within the permission mode you choose. That means you are responsible for:

  • choosing what each agent is allowed to do;
  • reviewing what an agent changed before you rely on it, especially code that is merged into your branches;
  • keeping backups, and keeping your work in version control;
  • pointing Marshal only at repositories and accounts you are allowed to change.

Where Marshal offers an undo or a backup, treat it as a help and not as a guarantee.
